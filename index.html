Salvar e transferir seus dados

Os cartões ficam guardados neste navegador e neste aparelho. Exporte um backup regularmente. Para passar seus cartões para outro aparelho, importe o arquivo JSON nele.

Sobre acesso por convite: esta primeira versão é individual e não sincroniza cartões entre pessoas. Para que apenas pessoas convidadas tenham contas e progresso sincronizado, será necessário conectar um serviço gratuito de autenticação e banco de dados numa próxima etapa. Não compartilhe dados pessoais neste protótipo.
